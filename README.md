# Karyra Spark

Clean rebuild workspace untuk Karyra Spark: local blockchain, cryptocurrency, Web3, dan Starknet gateway.

## Pilar produk

- Learn: kursus, jalur belajar, lesson, checkpoint, glossary.
- Practice: lab, simulasi, testnet-safe practice, wallet readiness.
- Community: workshop, cohort, event lokal, fasilitator.
- Passport: profil learner, progress, readiness, bukti belajar/praktik/partisipasi.
- Hub: gateway resource, apps, tools, games, komunitas, dan misi ekosistem.

## Commands

```bash
pnpm install
pnpm check
pnpm build
pnpm dev
```
