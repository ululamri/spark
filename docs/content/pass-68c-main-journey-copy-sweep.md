# Pass 68C — Main Journey Copy Sweep

## Tujuan

Spark harus terasa seperti teman belajar yang menuntun pengguna lokal/non-teknikal, bukan sistem yang menjelaskan arsitektur internal.

Pass ini membersihkan perjalanan utama pengguna:

1. Home: menjelaskan nilai Spark dengan empati dan CTA konkret.
2. Auth: membuat login/register terasa seperti menyimpan perjalanan belajar.
3. Dashboard: mengarahkan pengguna ke satu langkah berikutnya.
4. Core: menjadikan belajar sebagai langkah pertama, bukan ujian.
5. Lab: menjadikan simulasi aman sebagai aksi utama.
6. Passport: menjelaskan kesiapan dan bukti belajar.
7. Community: mengajak pengguna belajar bersama, bukan sekadar membuka tab.
8. Hub: menjelaskan Hub sebagai resource yang disarankan saat pengguna siap.

## Public language

- Gunakan bahasa pengguna: progres, bukti belajar, kesiapan, langkah berikutnya, tersimpan, siap.
- Hindari bahasa sistem di UI publik: backend, API, evidence root, proof ledger, local-state, sync queue.
- Jika istilah Starknet/Web3 harus muncul, beri konteks pendek dan jangan jadikan tombol pasif.
