# Pass 41A — Public Footer & Guest Navigation Cleanup

Tujuan pass ini adalah membuat landing/public surface terasa lebih profesional:

- Guest tidak melihat bottom nav app.
- Menu drawer tetap menjadi tempat navigasi publik di mobile.
- User login tetap mendapat bottom nav utama.
- Footer publik dibuat lebih lengkap dan terasa seperti penutup situs.
- Ruang kosong setelah footer dikurangi.

Prinsip:

- Bottom nav = navigasi aplikasi untuk user yang sudah masuk.
- Public footer = navigasi situs publik dan informasi dasar.
- Landing page tidak boleh terasa seperti app shell internal sebelum user masuk.
