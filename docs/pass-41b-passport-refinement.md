# Pass 41B — Passport Credential Refinement

Pass 41B memperkuat Passport sebagai produk utama Spark, bukan sekadar widget profil.

## Prinsip produk

- Profile = identitas akun pribadi.
- Passport = bukti kesiapan yang diterbitkan Spark.
- Passport menampilkan kesiapan, level, bukti belajar/latihan/komunitas/hub, dan langkah berikutnya.
- Verifikasi identitas kuat tetap opsional dan tidak menjadi syarat awal pengguna umum.

## Perubahan UI

- Hero Passport lebih ringkas dan berfokus pada kartu credential.
- Tambahan kartu credential: holder, handle, issuer, status, level, assurance, ID.
- Level Passport: Beginner, Intermediate, Advanced.
- Bukti kesiapan: Belajar, Lab, Komunitas, Hub.
- Privacy card dibuat lebih user-facing.
- Mobile layout diringkas agar tidak terasa berat.

## Batasan

Pass ini belum membuat sistem ujian level, KYC, backend credential, atau verifiable credential. Pass ini hanya mematangkan permukaan Passport agar siap menjadi mainline sebelum leveling Core/Lab dikerjakan.
