# Pass 44 — Proof Signals & Starknet Grant Scope

Pass 44 memperjelas keluarga proof Karyra Spark tanpa melakukan overbuild sebelum grant diterima.

## Batas implementasi saat ini

Dikerjakan sekarang:

- model ringan untuk keluarga proof Spark;
- section Passport yang memperlihatkan Proof-of-Learning, Proof-of-Practice, Proof-of-Safety, Proof-of-Participation, Proof-of-Exploration, dan Proof-of-Contribution;
- dokumentasi scope Starknet yang lebih luas untuk bahan grant;
- audit script agar arah Starknet tetap berada di roadmap, bukan implementasi berat.

Tidak dikerjakan sekarang:

- backend production;
- Cairo contract;
- deploy Sepolia/Mainnet;
- mint NFT;
- wallet live integration;
- public verifier;
- KYC nyata;
- admin/facilitator verification production.

## Proof family

Proof-of-Readiness adalah output utama Passport Spark. Proof ini dibangun dari beberapa sinyal:

1. Proof-of-Learning — hasil Core dan ujian level.
2. Proof-of-Practice — hasil Lab dan ujian praktik.
3. Proof-of-Safety — guardrail wallet, seed phrase, private key, signature, testnet/mainnet.
4. Proof-of-Participation — workshop, cohort, diskusi, dan community verification.
5. Proof-of-Exploration — Hub, resource Starknet, dan readiness path.
6. Proof-of-Contribution — kontribusi komunitas atau ekosistem, roadmap setelah grant.

## Starknet grant scope

Scope grant harus menunjukkan bahwa Spark bukan hanya edukasi tentang Starknet, tetapi produk yang mengintegrasikan ekosistem Starknet secara bertahap.

Milestone besar untuk grant:

1. Backend & Readiness Event Ledger.
2. Signed exam/event record.
3. Evidence root / Merkle commitment.
4. Cairo PassportRegistry.
5. Scarb build workflow.
6. Starknet Foundry testing and deployment workflow.
7. Sepolia MVP for proof anchoring.
8. Starknet Mainnet anchoring as final production target.
9. NFT / non-transferable Passport Badge.
10. StarknetKit wallet readiness flow.
11. Public verifier page.
12. Community verifier / facilitator attestation.
13. Hub ecosystem integration.
14. Dojo/provable Lab sandbox as future expansion.

## Product boundary

Sebelum grant diterima, Spark cukup menyiapkan public app, leveling, Passport proof foundation, proof signals, dan backend-ready structure.

Setelah grant diterima, full Starknet integration bisa dieksekusi secara bertahap dengan resource yang memadai.
