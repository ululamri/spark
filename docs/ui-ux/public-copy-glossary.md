# Public Copy Glossary — Karyra Spark

Gunakan glossary ini saat membersihkan CTA, halaman, panel, drawer, toast, dan microcopy.

| Hindari di UI publik | Gunakan untuk publik |
| --- | --- |
| backend | sistem Spark / akun Spark / server Spark jika benar-benar perlu |
| API | layanan Spark / koneksi Spark |
| endpoint | jalur layanan / fitur |
| local-state | data sementara di perangkat |
| sync queue | antrean penyimpanan / menunggu tersimpan |
| hydrate session | memuat sesi |
| unauthorized | sesi berakhir / masuk lagi |
| runtime | saat aplikasi berjalan / sekarang |
| smoke test | pengecekan cepat |
| route | halaman / jalur |
| migration | pembaruan data |
| proof event ledger | catatan bukti perjalanan |
| evidence root | ringkasan bukti |
| hash chain | jejak bukti berurutan |
| backend eligibility | pengecekan kelayakan |
| NFT-ready | siap dikembangkan menjadi credential on-chain |
| MinIO / S3 / storage registry | penyimpanan file |
| Docker / Caddy / PostgreSQL | jangan tampilkan di UI publik |
| developer/admin | internal / pengelola, hanya jika halaman memang internal |
