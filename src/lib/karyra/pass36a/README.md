# Pass 36A Runtime Notes

This folder records the Pass 36A decision:

- Home flow cards on mobile must not use a narrow text grid column.
- The module title should be clean: Core, Lab, Passport, Community, Hub.
- Action labels/chips can remain: Belajar, Praktik, Terbukti, Bersama, Jelajah.
- Descriptions must span the full card width.

If a later component refactor creates specific classes, prefer these names:

- `.home-flow-card`
- `.home-flow-card-header`
- `.home-flow-card-title`
- `.home-flow-card-copy`

The Pass 36A CSS already supports these names.
