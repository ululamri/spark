# Home Flow Visual Rhythm

Recommended mobile structure:

```txt
[1] [icon] Core
    Belajar

Belajar fondasi blockchain, crypto, Web3, wallet safety, dan pengantar Starknet.
```

Rules:

1. Do not put the paragraph in the same narrow grid column as the number badge.
2. Do not combine action label and module name into one title.
3. Keep the paragraph under 2–4 mobile lines when possible.
4. The right side of the card should never be empty while text wraps on the left.
5. Use contextual icons: book/core, flask/lab, badge/passport, users/community, compass/hub.
